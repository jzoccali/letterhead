Paste it

  1. Copy signature.
  2. Gmail → Settings → See all settings → General → Signature.
  3. Create new, paste, set as default, Save changes.
  1. Copy signature.
  2. Fastmail → Settings → Signatures.
  3. New signature, paste, assign to the identity.
  1. Copy signature (or Copy HTML for Classic Outlook).
  2. New Outlook: gear → Accounts → Signatures → New → paste.
  3. Classic: File → Options → Mail → Signatures. If paste strips formatting, replace the .htm file in %appdata%\Microsoft\Signatures with the HTML source.
  1. Copy signature.
  2. Mail → Settings → Signatures → + → paste.
  3. Untick “Always match my default message font.”
